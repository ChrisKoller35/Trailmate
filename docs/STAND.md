   *Bestanden:* `npx tsc --noEmit` und `npm run lint` ohne Fehler, CI-Lauf auf dem PR grün. Ohne diesen Schritt kann kein weiterer PR die Definition of Done aus [`AGENTS.md`](../AGENTS.md) erfüllen.
2. ✅ *Erledigt (Migration 009, Test `supabase/tests/009_protect_status_fields.test.sql`).* **`fix/premium-umgehung` – Dev-Vorschau entfernen und `is_premium` serverseitig schützen.** Den Dev-Vorschau-Knopf aus `app/(auth)/login.tsx` entfernen; neue Migration `009_protect_status_fields.sql`, die Änderungen an `is_premium` und `is_verified` durch normale Nutzer verhindert (Trigger oder Spaltenrechte); das direkte Update in `app/premium.tsx:33-36` entfernen (Kauf bleibt bis zur IAP-Anbindung deaktiviert).
